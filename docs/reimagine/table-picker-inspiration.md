# Table picker visual inspiration (Maz, 25 Oct 2026)
Reference: docs/reimagine/table-picker-inspiration.png (a Reddit r/SideProject post, "Would you book a table like this?"). Inspiration only; do not copy branding or UI chrome.
- Isometric, pale-grey floor plan with low walls and partitions; plants for warmth.
- Tables drawn with chairs round them (count = capacity). Different shapes: round, square, long banquet.
- Colour = state: neutral grey free, pink/red = hovered or taken, strong blue = selected. Table label (T1..T6) printed flat on the table top.
- A small floating white card shows the selected table (name, "Free", size).
Map to our tokens: free = neutral tint, selected = cobalt, taken = pink, with a text/pattern state as well (not colour only).
