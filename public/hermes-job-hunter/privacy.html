Hermes Job Hunter

Privacy policy

This policy describes the personal-use Hermes Job Hunter application and its read-only Gmail connection.

Gmail information accessed and used

This deployment requests the gmail.readonly permission. It checks the mailbox address, message identifiers, history and message headers. It reads the contents of messages marked for import: a subject beginning Fwd:, a configured label, an approved sender or a jobs alias.

It extracts candidate job links and proposes application-status updates. Unmarked messages are ignored after their headers are checked. The connection does not send, edit or delete email. The app has no advertising or AI-model-training functionality.

An optional read-only IMAP connection is also supported. If the operator enables it, the app uses locally stored app-password credentials instead of OAuth. The current deployment uses OAuth.

Storage and access

Job links, processing identifiers, tracking records, approved answers and status proposals are stored in the operator’s local application database. The profile and CV are kept in private files on the operator’s Windows computer. In this deployment, Gmail OAuth tokens are stored in Windows Credential Manager. Installations without that credential-store support can use file-based token storage and need their own access controls.

The app does not automatically delete imported records or processing metadata. The operator reviews removal requests. Minimal submission safeguards are retained permanently to prevent duplicate attempts; revoking Gmail access does not clear those safeguards.

Sharing and connected services

Selected job-tracking records can be mirrored to the operator’s configured Notion workspace. Configured model providers can assist with application drafts using selected job information, profile facts and CV text. Gmail OAuth credentials are not included in those drafting requests. Third-party services have their own data-handling terms and settings.

Submitting an employer application shares the relevant application details with that employer or its application platform only after explicit approval. Connecting Gmail does not itself authorize any employer submission. This information page does not provide public access to application records, messages, credentials or the operator’s browser sessions.

Use and transfer of information received from Google APIs are governed by the Google API Services User Data Policy, including its Limited Use requirements. Connected services must be configured consistently with those requirements.

Revoking access and requesting removal

The operator can revoke Google access through Google Account connections. Revoking access stops future Gmail API access; it does not automatically remove records already imported. Contact jobhubtbot@gmail.com to request access or removal of retained application data.
